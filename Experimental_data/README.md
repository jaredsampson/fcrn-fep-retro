# Experimental_data

This directory contains the experimental data used in the study.

Data from each literature source is included in the `source` subdirectory, with
new measurements from the current study in `Current_work.csv`.

The data was compiled from the individual sources into
`full_retrospective_dataset.csv`, which reproduces all the individual data and
prepares dG values from the original affinity Kd values.  Results for each
variant are also averaged in `variants_dataset.csv`, which is used for the
analysis in the paper.

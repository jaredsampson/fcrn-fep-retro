# fcrn-fep-retro

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19777392.svg)](https://doi.org/10.5281/zenodo.19777392)

Data and code for a retrospective Fc-FcRn FEP study.

## Contents

The repository consists of the following directories:

- *Experimental_data* = experimental data used for comparison with FEP results.
- *Input_structures* = prepared input structure files used in the manuscript.
- *FEP_results* = output files from Protein FEP Groups analysis of FEP output.
- *Edge_convergence* = edge-level convergence metrics for the initial retrospective FEP calculations.
- *Normal_mode_analysis* = input and output files for normal mode analysis of Fc
  structures.
- *Scripts* = Python scripts used for preparing and merging experimental data and
  FEP output files.
